# Alcance de publicación MD4 PPS

Se publica únicamente el estado agregado de PPS, la tabla agregada de verificación aritmética y las fórmulas propuestas para ratificación. No se publican hojas con descripciones/pares identificables ni calificaciones individuales. Las fuentes MD-4 v2 ya están en `../md4/evidencias/` (ruta hermana `../md4/evidencias/` desde semana12-v2); no se duplican.
